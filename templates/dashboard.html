ℹ️ Comment lire
  • 🔥 Timing d'entrée : c'est le plus important. Il regarde combien de bougies M5 se sont écoulées depuis le croisement EMA5/EMA25. Si ≤ 5 bougies → FRAIS (lot plein). Si 6-12 → EN COURS (demi-lot). Si > 12 → TARDIF (n'entre pas, attends le prochain croisement). C'est ça qui fait la différence entre entrer au début du mouvement et acheter le sommet.
  • 🛡️ Verdict global : combine tous les filtres (session, volatilité, tendance H4/H1, timing, duplication, corrélation). Si c'est "BLOQUÉ" en rouge, ne prends pas le trade même si le signal est vert. Si c'est "PRUDENCE" en jaune, réduis ton lot ou attends. Si c'est "FEU VERT", alors tu peux trader.
  • Session : les meilleures heures sont le chevauchement Londres+New York (15h-18h heure du Bénin) et Londres seul (9h-15h). En Asie (1h-9h) et la nuit, les signaux sont peu fiables.
  • Tendance H4/H1 : si H4 ET H1 sont contre ton signal, c'est un pullback (piège) → BLOQUÉ. Si un seul est contre → PRUDENCE, réduis ton lot.
  • Signal récent : si le même signal a été donné il y a moins de 30 min, ce n'est pas un nouveau signal, c'est le même mouvement.
  • Corrélation : EURUSD et GBPUSD bougent souvent ensemble. Prendre les deux = doubler ton risque.
  • 🧮 Tendance générale pondérée : combine tous les TF avec un poids. Les petits TF (M5×5, M15×4) pèsent plus lourd que les grands (M30×3, H1×2, H4×1), car ils reflètent le mouvement récent.
  • Alignement progressif : on regarde M5 → M15 → M30 → H1. Si les 4 sont dans le même sens, alors le mouvement est cohérent.
  • Confirmation : si M15+M30+H1 alignés ET croisement EMA M5 récent (≤3 bougies) après clôture dans le même sens, alors ACHAT ou VENTE confirmé.
  • Signal « détecté » : les timeframes vont dans le même sens. Ce n'est pas une garantie que le prix continue.
  • Ach. / Ven. = % de bougies vertes / rouges sur les 10 dernières.
  • Agit. = part du mouvement perdue en allers-retours. Si c'est haut, alors le marché est indécis.
  • Div. : H = divergence haussière, B = divergence baissière, — = aucune.
  • « N bg » = nombre de bougies depuis le croisement EMA ou la cassure.
  • Cassure : le prix a fermé au-dessus du plus haut (↑) ou sous le plus bas (↓) des 20 bougies d'avant.
  • Mèche basse : les vendeurs ont essayé de pousser et ont échoué. Mèche haute : l'inverse.
  • Englobante : la dernière bougie avale entièrement la précédente.
  • Grande ×N : la bougie est N fois plus grande que la moyenne. Si N ≥ 2, alors attends.
  • Stop : sous le dernier creux (achat) ou au-dessus du dernier sommet (vente). Si le ratio est sous 1,5, le trade ne vaut pas le coup.
  • Lot : calculé pour un compte en dollars (EURUSD, GBPUSD, or). Vérifie avec le calculateur de ta plateforme. Pour V75, le lot n'est pas calculé.
  • Test sur le passé : c'est une indication, pas une garantie. Le spread n'est pas compté.
  • 🔔 Son : si tu l'actives, alors un bip t'avertit d'un nouveau signal tant que la page reste ouverte.
  • Toutes les bougies en cours sont ignorées : seules les bougies clôturées comptent.
