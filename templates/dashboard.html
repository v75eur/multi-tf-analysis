ℹ️ Comment lire
  • Ach. / Ven. = % de bougies vertes / rouges sur les 10 dernières.
  • Agit. = part du mouvement perdue en allers-retours. Si c'est haut, alors le marché est indécis.
  • Div. : H = divergence haussière, B = divergence baissière, — = aucune.
  • « N bg » = nombre de bougies depuis le croisement EMA5 / EMA25 ou depuis la cassure. Si N est grand, alors l'entrée est tardive.
  • Cassure : le prix a fermé au-dessus du plus haut (↑) ou sous le plus bas (↓) des 20 bougies d'avant.
  • Mèche basse : les vendeurs ont essayé de pousser et ont échoué (signe d'achat). Mèche haute : l'inverse.
  • Englobante : la dernière bougie avale entièrement la précédente (possible retournement).
  • Grande ×N : la bougie est N fois plus grande que la moyenne. Si N ≥ 2, alors attends.
  • Stop : sous le dernier creux (achat) ou au-dessus du dernier sommet (vente). Si le ratio est sous 1,5, alors le trade ne vaut pas le coup.
  • Test sur le passé : c'est une indication, pas une garantie. Si le nombre de signaux est petit, alors le résultat n'est pas sûr.
  • 🔔 Son : si tu l'actives, alors un bip et une vibration t'avertissent d'un nouveau signal tant que la page reste ouverte. Si l'écran du téléphone est verrouillé, alors rien ne sonne.
  • Toutes les bougies en cours sont ignorées : seules les bougies clôturées comptent.
