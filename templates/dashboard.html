ℹ️ Comment lire le bot
  • 🤖 Le bot te dit quoi faire : "ENTRE MAINTENANT" (vert), "PRUDENCE — DEMI-LOT" (jaune), "N'ENTRE PAS" (rouge), "ATTENDRE" (gris).
  • Chaque conseil est unique : il combine session + timing + tendance H4/H1 + volatilité + résistance + ratio + corrélation.
  • 📒 Le journal du bot garde la trace de ses conseils.
  • 🔥 Timing d'entrée : ≤5 bougies M5 depuis le croisement EMA = frais (lot plein), 6-12 = en cours (demi-lot), >12 = tardif (n'entre pas).
  • Toutes les bougies en cours sont ignorées : seules les clôturées comptent.
  • Teste en démo 2-3 semaines minimum.
