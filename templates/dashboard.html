ℹ️ Comment lire — Nouvelle stratégie : SIGNAUX BOUGIES
  • 🕯️ Signaux bougies : le déclencheur d'entrée est maintenant un signal visible sur les bougies M5.
  • 3 types de signaux acceptés :
    • 3 bougies successives dans le sens (3 vertes = ACHAT, 3 rouges = VENTE) — fiabilité 78%
    • Grande bougie (×2 la taille moyenne) dans le sens — fiabilité 75%
    • Englobante (bougie qui avale la précédente) dans le sens — fiabilité 63%
  • Priorité : Grande bougie > Englobante > 3 bougies. Le signal le plus fort est retenu.
  • Contexte obligatoire : H1 + M30 + M15 alignés dans le même sens + RSI > 50 (achat) ou < 50 (vente).
  • Croisement EMA : affiché dans le tableau pour information, mais ne déclenche plus l'entrée.
  • RSI : 14 standard, 7 sur M5. Affiché en % acheteurs/vendeurs.
  • 🎯 Décision : le bot te dit ENTRE MAINTENANT / PRUDENCE / N'ENTRE PAS / ATTENDRE.
  • ⚠️ 10 $ : le lot minimum 0.01 fait risquer plus de 1 % par trade sur la plupart des paires. Le bot te le dira.
  • 🔔 Son + 🔊 Voix : alerte quand signal bougies apparaît ou quand verdict change.
