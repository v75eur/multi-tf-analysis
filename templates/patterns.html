ℹ️ Comment lire ce tableau
  • Pattern : combinaison de tendance + état EMA + force acheteurs + agitation + motif de bougie.
  • Nb : combien de fois ce pattern est apparu dans l'année observée.
  • Monte / Descend : pourcentage des fois où, 4h après le pattern, le prix était plus haut / plus bas.
  • Var moy 4h : variation moyenne du prix 4h après le pattern (en %).
  • Amp moy 4h : amplitude moyenne (haut-bas) sur les 4h qui suivent.
  • Biais : 📈 monte si ≥55% de hausses, 📉 descend si ≥55% de baisses, ↔️ plat sinon.
  • Un pattern à 70%+ de fiabilité est intéressant mais pas garanti. Le marché change. À vérifier dans le contexte du moment.
  • Le nombre d'occurrences compte : 10 observations = peu fiable, 100+ = plus sérieux.
