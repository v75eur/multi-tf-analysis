ℹ️ Comment lire ce tableau
  • Pattern : combinaison tendance + EMA + acheteurs + agitation + motif.
  • Nb : combien de fois ce pattern est apparu depuis 1 an.
  • Monte / Descend : % des fois où, 4h après, le prix était plus haut / plus bas.
  • Var moy 4h : variation moyenne 4h après le pattern.
  • Amp moy : amplitude moyenne sur les 4h suivantes.
  • Biais : 📈 monte si ≥60% hausses, 📉 descend si ≥60% baisses, ↔️ plat sinon.
  • Dates : période couverte par les observations.
  • 20 observations = minimum, 100+ = plus sérieux. Un pattern à 70%+ est intéressant, pas garanti.
